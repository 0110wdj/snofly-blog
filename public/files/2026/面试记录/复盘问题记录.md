## 技术问题

### 1、React 中事件绑定和 js 中事件绑定的区别？

---

1. 基本写法区别

```js
// 原生 JS：全小写，传字符串
btn.onclick = handleClick;
btn.addEventListener('click', handleClick);
<button onclick="handleClick()">

// React：驼峰命名，传函数（不是字符串），用 JSX
<button onClick={handleClick}>
```

---

2. 核心区别：合成事件（SyntheticEvent）

React 的事件不是原生 DOM 事件，而是 React 自己封装的 SyntheticEvent：

- 跨浏览器兼容（抹平 IE 等差异，现在意义减弱但机制保留）
- API 和原生事件一致：e.preventDefault()、e.stopPropagation()、e.target 等
- 但不能用 return false 阻止默认行为，必须显式调 e.preventDefault()

---

3. 事件委托机制（最重要的区别）

原生 JS： 事件直接绑定在每个 DOM 节点上：

```js
// 100 个按钮就要绑 100 次
document.querySelectorAll('button').forEach(btn => {
  btn.addEventListener('click', handler);
});
```

React： 事件统一委托到根节点（React 17+ 是 root 容器，React 16 是 document）：

你写的 onClick={fn}
   ↓ 并没有绑在 button DOM 上
事件统一绑在 #root 上
   ↓ 事件冒泡到 root 时，React 按虚拟 DOM 树找到对应 handler 执行

好处：
- 减少内存占用，不用给每个节点绑监听器
- 动态新增/删除节点时不用手动绑定/解绑

---

4. 执行时机和冒泡的差异（面试高频坑）

```js
function App() {
  const ref = useRef();

  useEffect(() => {
    // 原生监听：在真实 DOM 上
    ref.current.addEventListener('click', () => {
      console.log('原生事件');
    });
  }, []);

  return <button ref={ref} onClick={() => console.log('React 事件')}>点我</button>;
}
```

点击后输出顺序：

原生事件          ← 目标元素上的原生监听先触发
React 事件        ← 冒泡到 root 容器时才触发

因为 React 17+ 的监听器挂在 root 容器上，原生事件先在目标节点执行，冒泡到 root 后 React 事件才执行。

---

5. e.stopPropagation() 的坑

React 合成事件的 stopPropagation 挡不住外层的原生事件，反之亦然：

```js
document.addEventListener('click', () => console.log('document 原生'));

<div onClick={e => { e.stopPropagation(); console.log('React'); }}>
```

点击后 document 上的原生监听仍然会触发（React 17+ 挂在 root 容器上，stopPropagation 只能阻止 React 合成事件体系内的传播）。

如果必须阻止，用 e.nativeEvent.stopImmediatePropagation()。

---

6. 事件池（Event Pooling）——历史考点

- React 16 及以前：合成事件对象会被复用，异步访问 e 的属性会是 null，需要 e.persist()
- React 17 起已移除事件池，可以直接异步访问，现在面试提一句"知道这个历史机制"即可

```js
// React 16 的坑
onClick={(e) => {
  setTimeout(() => console.log(e.target), 0); // null！需要 e.persist()
}}
```

---

7. Class 组件中的 this 绑定

原生 JS 不存在这个问题，React class 组件需要处理 this：

```js
class App extends React.Component {
  handleClick() { console.log(this); } // undefined！

  render() {
    return (
      <>
        <button onClick={this.handleClick.bind(this)}>方案1 bind</button>
        <button onClick={() => this.handleClick()}>方案2 箭头函数</button>
        <button onClick={this.handleClick}>方案3 构造函数/类字段</button>
      </>
    );
  }
}
```

函数组件没有这个问题。
