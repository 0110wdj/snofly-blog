### 企业级模糊测试平台｜架构迁移与核心功能研发

- **跨端架构与代码复用：** 使用 Git Submodule 维护共享业务代码，通过环境变量区分运行环境，结合 React Router 统一路由配置，并通过 IPC 封装适配 Electron API 与 Node.js 模块，实现共享业务代码同时支持 Web 与桌面端。
- **实时通信与数据传输优化：** 基于 WebSocket 实现控制指令双向通信，使用 SSE 传输测试进程日志；开发开源 npm 包 [`json-string-pack`](https://www.npmjs.com/package/json-string-pack)，用于压缩动态嵌套 JSON 数据，在样本测试中将 9MB 数据压缩至约 500KB；对固定结构消息采用 Protobuf 二进制序列化。
- **SDK 测试进程管理：** 参与前后端功能开发。前端提供 Docker 镜像地址、启动命令及参数配置；后端通过分布式 Runner 节点执行测试任务，节点通过 Client Code 登录平台并上报信息，平台根据节点 IP 和容器 ID，通过 SSH 控制目标节点执行 Docker 命令，完成 SDK 镜像拉取、容器启动及测试进程管理，并支持状态、结果查询和日志获取。
- **单点登录（SSO）改造：** 将原有基于 Spring Security 的认证流程扩展为支持 OIDC 的单点登录方式，增加外部平台 SSO 登录入口。前端实现登录参数处理与自动跳转，后端负责 SSO Token 解析、用户及关联数据自动创建，以及 Client ID、Client Secret 的维护；保留原有 Access Token 接口鉴权机制及 Client Code 登录方式，兼容 SDK 既有登录流程。
- **邮件配置与发送：** 实现邮件配置前端组件，支持发件人及鉴权码配置；后端负责配置保存与邮件发送，并通过切面逻辑在程序执行流程中触发自动邮件发送。
- **复杂业务功能建设：** 基于 JSON Schema 实现动态表单生成，通过 WebSocket 接收 SDK 程序发送的配置，实现由 SDK 控制前端页面展示内容。
